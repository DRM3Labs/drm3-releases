## Product-Specific Terms

Connor scans publicly available DNS records (A, AAAA, MX, TXT, NS, CNAME, SOA, CAA), WHOIS data, and certificate transparency logs. All scanned data originates from public sources. Connor does not access private networks, authenticated services, or non-public infrastructure.

API access requires an API key for rate limiting and access control. API keys are associated with service identity, not personal identity.

## Scanned Data

DNS records, WHOIS responses, and certificate transparency logs are public by nature. Connor aggregates and indexes this data for intelligence purposes. Domain owners do not need to consent to public DNS resolution — this is how the internet works.

## Provenance Receipts

Connor generates cryptographic provenance receipts (content hashes and signatures) for each scan. These receipts attest to what was observed at a point in time. Provenance receipts are informational and do not constitute legal proof or certification of any kind.

# Privacy Policy — RunsWith

**DRM3 Labs Corp. · Last updated: March 23, 2026**

RunsWith is a DNS intelligence and service fingerprinting platform operated by DRM3 Labs Corp.

This policy supplements the [general DRM3 Privacy Policy](../PRIVACY.md).

## Data Practices

RunsWith analyzes DNS signal data sourced from Connor. All underlying data — DNS records, WHOIS responses, certificate transparency logs — is publicly available. RunsWith's fingerprinting engine identifies technology providers from this public data. No private or authenticated data is accessed.

## API Access

API access requires an API key for rate limiting and access control. We do not correlate API keys to personal identity. API request content is not logged or stored beyond operational metrics (request counts for rate limiting).

## What We Don't Collect

- No personal information
- No tracking or analytics
- No cookies
- No user accounts or profiles
- No browsing history

## Intelligence Reports

RunsWith generates service detection reports and technology stack analyses. These reports describe publicly observable infrastructure. Domain owners cannot opt out of public DNS resolution. If you believe RunsWith is displaying inaccurate information about your domain, contact us.

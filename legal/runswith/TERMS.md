## Product-Specific Terms

RunsWith consumes DNS signal data from Connor and applies service fingerprinting to identify technology providers, hosting platforms, email services, CDNs, and other infrastructure used by scanned domains. All analysis is derived from publicly available DNS records.

RunsWith's fingerprinting is based on pattern matching against known provider signatures. Detections are probabilistic and may be inaccurate. RunsWith does not guarantee the accuracy or completeness of any service identification.

API access requires an API key for rate limiting and access control. API keys are associated with service identity, not personal identity.
